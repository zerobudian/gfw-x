# GFW X example rule set — Developer preset (TXT format)
# Format: ALLOW / BLOCK / OBSERVE / RATELIMIT <value>
#   value starting with `*.` matches the domain and all subdomains (suffix/wildcard)
#   *_CATEGORY <name> blocks an entire category (social-media, adult, gambling, malicious, vpn-tunnel)
# Priority: explicit allow > explicit block > category rule > default policy

# --- Block categories first (category rules rank below explicit allows) ---

BLOCK_CATEGORY gambling
